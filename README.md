Aim:
To understand and apply tuples in Python.

In this program, we explored the concept of tuples and examined how they differ from lists in Python. Unlike lists, tuples are immutable, meaning their elements cannot be modified or appended after creation. We began by creating tuples and performing basic operations such as calculating the minimum, maximum, and average values of a given dataset. The data was then sorted in ascending order for better analysis.

The next task involved result analysis using tuples. We unpacked the tuple values and assigned performance categories based on specific conditions. For example, if a student scored greater than or equal to 75, the program displayed the result as “Distinction.” Similar conditions were applied for other grading criteria, and the appropriate result was printed accordingly.

In the second task, we created tuples to manage employee attendance records, specifically tracking presentee and absentee data. After unpacking the tuples, conditions were applied to determine attendance status. If an employee was absent for a week or more, the program displayed a notification stating that the employee was absent atleast once this week. Finally, the total number of days each employee was present and absent was calculated, and the corresponding results were displayed.

Overall, this program enhanced our understanding of tuples, tuple unpacking, conditional statements, and basic data analysis in Python.
